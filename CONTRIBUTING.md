# Contributing to GreenCalculus Standards

Thanks for your interest! This repository maps the global GHG accounting standards that
GreenCalculus aligns with — GHG Protocol, Scope 3, IPCC AR6, ISO 14064-1, CSRD/ESRS E1,
SBTi, DEFRA, and more. It is published under CC-BY-4.0 and we welcome corrections and
additions from the community.

## Ways to contribute

- **Correct a mapping** — if a standard reference, clause, or alignment claim is inaccurate
  or out of date, open an [issue](../../issues) or PR with the correction **and a citation**
  to the standard (document, version/year, section).
- **Add a standard** — propose a framework we should map (with a link to the official source).
- **Track an update** — flag a new version of a standard (e.g. a revised ESRS or GHG Protocol
  guidance) that needs reflecting.
- **Documentation** — fix typos, broken links, or unclear wording.

## Submitting a pull request

1. Fork and create a branch.
2. Keep changes focused; cite the standard for every change.
3. Describe **what** changed, **why**, and **the source clause/version**.
4. Open the PR against `main`.

## Ground rules

- Reuse is encouraged under CC-BY-4.0 — please attribute GreenCalculus.
- Every claim must reference the official standard text.
- Be respectful and constructive.

Questions? Open an issue or reach us at hello@greencalculus.com.
