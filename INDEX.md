# Standards Registry

The complete index of standards, frameworks, and factor sets tracked by GreenCalculus.

Each entry links to the GitHub mapping document (where available) and the live reference page on [greencalculus.com](https://greencalculus.com). GitHub mapping documents are being added in priority order — entries marked "doc pending" will be filled in over the coming weeks.

Status legend:
- **Implemented** — actively used in one or more live calculators
- **Mapped** — live reference page present at greencalculus.com/standards/* and GitHub mapping document published
- **Live-only** — live reference page present; GitHub mapping document pending
- **Monitored** — not yet documented; under review for future inclusion
