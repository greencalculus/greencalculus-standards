# Standards Registry

The complete index of standards, frameworks, and factor sets tracked by GreenCalculus.

Each entry links to the GitHub mapping document (left) and the live reference page on [greencalculus.com](https://greencalculus.com) (right).

Status legend:
- **Implemented** — actively used in one or more live calculators
- **Mapped** — documentation present in this repo; calculator implementation pending
- **Monitored** — not yet documented; under review for future inclusion
